# 3. Model-Free RL: Monte Carlo, TD, SARSA и Q-Learning

## 3.1. Зачем нужен model-free подход

В реальных задачах переходы среды обычно неизвестны, дороги для симуляции или меняются со временем. Вместо явной модели агент учится по собственному опыту — последовательностям `(state, action, reward, next_state, done)`.

## 3.2. Monte Carlo

Monte Carlo обновляет оценку после завершения эпизода:

$$V(S_t) \leftarrow V(S_t) + \alpha(G_t - V(S_t)).$$

Плюс: target использует полный return. Минус: нужно ждать конца эпизода, а оценка может иметь высокую дисперсию.

## 3.3. Temporal Difference

TD обновляет оценку после одного перехода:

$$V(S_t) \leftarrow V(S_t) + \alpha[R_{t+1} + \gamma V(S_{t+1}) - V(S_t)].$$

Выражение в квадратных скобках называется TD error. TD быстрее получает feedback, но использует bootstrap — оценку через другую оценку.

## 3.4. SARSA

SARSA — on-policy метод. Его переход имеет вид:

$$S_t,A_t,R_{t+1},S_{t+1},A_{t+1}.$$

Обновление:

$$Q(S_t,A_t) \leftarrow Q(S_t,A_t) + \alpha[R_{t+1} + \gamma Q(S_{t+1},A_{t+1}) - Q(S_t,A_t)].$$

SARSA обучается для поведения, которое агент действительно выполняет, включая exploration. В среде с опасными состояниями он часто выбирает более осторожную стратегию.

## 3.5. Q-Learning

Q-Learning — off-policy метод:

$$Q(S_t,A_t) \leftarrow Q(S_t,A_t) + \alpha[R_{t+1} + \gamma \max_a Q(S_{t+1},a) - Q(S_t,A_t)].$$

Target использует лучшее следующее действие, даже если текущая behavior policy иногда выбирает случайные действия. После обучения greedy policy выбирает `argmax_a Q(s,a)`.

## 3.6. Сравнение

| Метод | Тип | Target | Нужен завершённый эпизод |
|---|---|---|---|
| Monte Carlo | value-based | полный return | да |
| SARSA | on-policy TD | фактически выбранное следующее действие | нет |
| Q-Learning | off-policy TD | максимальное следующее действие | нет |

## 3.7. Практическая диагностика

Логируйте не только среднюю награду:

- epsilon;
- длину эпизода;
- долю успешных эпизодов;
- среднюю абсолютную TD error;
- число посещений состояний.

Если reward не растёт, проверьте отдельно: корректность `done`, знаки наград, индексацию действий, seed и скорость уменьшения epsilon.
